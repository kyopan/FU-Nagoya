# FU Winch v2 - RP2040 Eval Hardware Test

**作成日**: 2025-11-17
**バージョン**: 0.1-test
**MCU**: Waveshare RP2040-Zero
**目的**: winch_rp2040_eval基板のハードウェアユニットテスト

---

## 概要

winch_rp2040_eval基板の各ハードウェアコンポーネントを個別にテストするためのファームウェアです。

**テスト項目:**
1. Onboard LED (NeoPixel GPIO 16)
2. LED PWM (GPIO 14)
3. Electromagnetic Brake / Solenoid (GPIO 26)
4. Stepper Motor (TMC2209 via GPIO 0,1,2,7,8)
5. End Switch / Homing Sensor (GPIO 15)
6. I2C Communication (Slave mode, address 0x08, GPIO 4/5)

## シリアルコマンド

### テストコマンド

| コマンド | 動作 | 詳細 |
|---------|------|------|
| `1` | Onboard LED テスト | RGB色サイクル（赤→緑→青）5秒間 |
| `2` | LED PWM テスト | 輝度スイープ（0→255→0）5秒間 |
| `3` | 電磁ブレーキテスト | ロック/アンロック切替（1秒間隔）5秒間 |
| `4 <steps>` | ステッパーモーターテスト | 指定ステップ数移動（デフォルト: 1000） |
| `5` | エンドスイッチテスト | センサー値連続表示（任意キーで停止） |
| `6` | I2C通信テスト | スレーブモード受信監視（任意キーで停止） |
| `h` | ヘルプ表示 | コマンド一覧 |
| `i` | TMC2209情報表示 | バージョン、マイクロステップ、電流値 |
| `r` | 全出力リセット | 全LED消灯、モーター停止、ブレーキロック |

## テスト手順

### 1. Onboard LED テスト

**コマンド:** `1`

**期待動作:**
- オンボードNeoPixel LEDが以下の順で5秒間点灯
  1. 赤色（約1.7秒）
  2. 緑色（約1.7秒）
  3. 青色（約1.7秒）

**確認項目:**
- [ ] LEDが正しく点灯するか
- [ ] 色が正しく切り替わるか
- [ ] 5秒後に自動消灯するか

---

### 2. LED PWM テスト

**コマンド:** `2`

**期待動作:**
- 外部LED（GPIO 14）の輝度が5秒間で以下のように変化
  1. 消灯 → 最大輝度（2.5秒）
  2. 最大輝度 → 消灯（2.5秒）

**確認項目:**
- [ ] LEDが滑らかに明るくなるか
- [ ] 最大輝度に達するか
- [ ] 滑らかに暗くなるか
- [ ] 5秒後に完全消灯するか

---

### 3. 電磁ブレーキテスト

**コマンド:** `3`

**期待動作:**
- ソレノイド（電磁ブレーキ）が1秒間隔でロック/アンロック切替
- シリアルモニターに状態表示

**確認項目:**
- [ ] アンロック時にソレノイドが動作するか
- [ ] ロック時にソレノイドが停止するか
- [ ] 1秒間隔で正しく切り替わるか
- [ ] 5秒後にロック状態で終了するか

**注意:**
- テスト時間は5秒に制限されています

---

### 4. ステッパーモーターテスト

**コマンド:** `4` または `4 <steps>`

**例:**
```
4          # 1000ステップ移動（デフォルト）
4 500      # 500ステップ移動
4 2000     # 2000ステップ移動
```

**期待動作（⚠️ 重力負荷対応の安全シーケンス）:**
1. TMC2209初期化
2. **モーター有効化（ENABLE先行で保持トルク確保）**
3. 200ms待機（電流安定化）
4. **電磁ブレーキ解除（モーターが既に荷重を保持）**
5. 指定ステップ数だけ移動
6. **電磁ブレーキロック（モーター保持中に先行ロック）**
7. 200ms待機（ブレーキ係合確認）
8. **モーター無効化（ブレーキが既に保持）**

**確認項目:**
- [ ] TMC2209が正常に初期化されるか（`i`コマンドで確認）
- [ ] **モーターENABLE後、自由落下しないか（⚠️ 保持トルク確認）**
- [ ] **ブレーキ解除時、荷重がモーターで保持されているか（⚠️ 最重要）**
- [ ] モーターが指定方向に回転するか
- [ ] 指定ステップ数で正しく停止するか
- [ ] 動作音が正常か（異音・ガタつきがないか）
- [ ] **停止時、ブレーキが先にロックされるか（⚠️ モーター保持中）**
- [ ] **ブレーキロック後、モーター無効化で荷重が移行するか**

**TMC2209設定:**
- RMS電流: 800mA
- マイクロステップ: 16分周
- 最大速度: 1000 steps/s
- 加速度: 500 steps/s²

---

### 5. エンドスイッチテスト

**コマンド:** `5`

**期待動作:**
- センサー状態を100ms間隔で連続表示（デジタル入力）
- LOW (0) = "[TRIGGERED]" 表示（スイッチ押下時）
- HIGH (1) = "[OPEN]" 表示（スイッチ開放時）
- 任意キーで停止

**確認項目:**
- [ ] センサー状態が正しく読み取れるか
- [ ] エンドスイッチ押下時、LOW (0) になるか
- [ ] エンドスイッチ開放時、HIGH (1) になるか
- [ ] 表示が正しく更新されるか

**入力方式:** デジタル入力（`INPUT_PULLUP`）

---

### 6. I2C通信テスト

**コマンド:** `6`

**期待動作:**
- I2Cスレーブモード（アドレス: 0x08）で待機
- ESP32-C6（U1）からのコマンド受信を監視
- 受信データを16進数で表示
- コマンド種別を解析（H=HOMING, M=MOVE, S=STOP）
- 任意キーで停止

**確認項目:**
- [ ] I2Cスレーブとして初期化されるか
- [ ] ESP32-C6からのデータを受信できるか
- [ ] 受信データが正しく表示されるか
- [ ] コマンド解析が正常に動作するか

**I2C設定:**
- スレーブアドレス: 0x08
- SDA: GPIO 4
- SCL: GPIO 5
- クロック: 100kHz（標準モード）

**テスト方法:**
```bash
# RP2040側でテストモード起動
6

# ESP32-C6側から送信（別途U1ファームウェアで実施）
# 'H' コマンド → ホーミング開始
# 'M' + データ → 移動コマンド
# 'S' コマンド → 停止
```

## トラブルシューティング

### TMC2209初期化失敗

**症状:** `i`コマンドで "Communication error" 表示

**確認項目:**
1. UART配線確認（GPIO 0: TX, GPIO 1: RX）
2. TMC2209電源供給確認
3. アドレス設定確認（0b00）

**対処:**
```bash
# シリアルモニターで再初期化試行
i
```

---

### ステッパーモーターが動かない

**症状:** `4`コマンド実行後、モーター無反応

**確認項目:**
1. TMC2209初期化確認（`i`コマンド）
2. モーター配線確認
3. 電源電圧確認（24V供給）
4. ENABLE信号確認（GPIO 2）

**対処:**
```bash
# 全リセット後、再テスト
r
i
4 100
```

---

### エンドスイッチ反応しない

**症状:** センサー状態が常に一定（LOW or HIGH固定）

**確認項目:**
1. センサー配線確認（GPIO 15）
2. スイッチタイプ確認（NO: Normally Open / NC: Normally Closed）
3. INPUT_PULLUP設定確認

**対処:**
```bash
# センサー状態連続確認
5
# 手動でスイッチ押下し、LOW (0) ↔ HIGH (1) 変化を確認
# 常にLOW → 配線ショート or NC接点
# 常にHIGH → 配線断線 or NO接点未接続
```

## ハードウェア仕様

### ピン配置

```cpp
PIN_ONBOARD_LED   16  // NeoPixel (オンボード)
PIN_LED_PWM       14  // 外部LED PWM制御
PIN_SENSOR        15  // エンドスイッチ（デジタル入力、INPUT_PULLUP）
PIN_SOLENOID      26  // 電磁ブレーキ（PWM出力）
PIN_TMC2209_EN     2  // TMC2209 Enable (LOW=有効)
PIN_TMC2209_TX     0  // UART TX
PIN_TMC2209_RX     1  // UART RX
PIN_TMC2209_STEP   7  // ステップパルス
PIN_TMC2209_DIR    8  // 方向制御
PIN_U2_SDA         4  // I2C SDA
PIN_U2_SCL         5  // I2C SCL

U2_SLAVE_ADDRESS 0x08  // I2Cスレーブアドレス
```

- **RAM**: 3.9% (10,292 bytes / 262,144 bytes)
- **Flash**: 3.9% (80,888 bytes / 2,093,056 bytes)
- **ファームウェアサイズ**: 約79KB (.uf2)
