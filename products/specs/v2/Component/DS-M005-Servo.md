## 制御仕様

### PWM信号

| 項目 | 仕様 |
|------|------|
| **周波数** | 50Hz (20ms周期) |
| **Duty比範囲** | 5-10% (1.0-2.0ms) |
| **制御GPIO** | ESP32-S3 #2 (未割当) |
| **制御Core** | Core 1 |

### 角度制御

```cpp
// 角度 → PWM幅変換（推定）
// 0° → 1.0ms
// 90° → 1.5ms
// 180° → 2.0ms

float angle_to_pwm(float angle) {
  return 1.0 + (angle / 180.0); // ms
}

// ESP32 LEDC PWM設定
ledcSetup(PWM_CHANNEL, 50, 16); // 50Hz, 16-bit分解能
ledcAttachPin(SERVO_PIN, PWM_CHANNEL);

// 角度指定
void set_servo_angle(float angle) {
  uint16_t duty = (uint16_t)(angle_to_pwm(angle) * 3276.8); // 16-bit
  ledcWrite(PWM_CHANNEL, duty);
}
```

### サーボ取付

| 項目 | 仕様 |
|------|------|
| **取付位置** | HD基板右端 |
| **取付方法** | ネジ固定 or 基板穴固定 |
| **サーボホーン** | 樹脂製（付属品想定） |

### PR制御機構

```
サーボ本体 (HD基板) → サーボホーン → PR取付機構 → GR/CR Ring
                               ↓
                        Pitch軸回転（傾き制御）
```

**制御ロジック:**
```cpp
// 目標角度と推定角度の差分制御
float target_angle = 90.0;
float estimated_angle = current_pwm_to_angle();

if (abs(target_angle - estimated_angle) > THRESHOLD) {
  set_servo_angle(target_angle);
}
```
