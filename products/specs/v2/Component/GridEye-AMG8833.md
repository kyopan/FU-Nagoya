## I2C通信仕様

| 項目 | 仕様 |
|------|------|
| **I2Cアドレス** | 0x68 (固定) |
| **I2Cバス** | I2C0系統 (HD ESP32-S3 #1) |
| **クロック周波数** | 100kHz |
| **プルアップ抵抗** | ESP32-S3内部プルアップ使用 |
| **バス長** | 最大15cm程度 (HD → PR → GR) |

**接続経路:**
```
HD (ESP32-S3 #1) → PR取付機構 → GR Board → AMG8833
  ↓
I2C0 (SDA/SCL)
```

## データフォーマット

### 温度データ

| 項目 | 仕様 |
|------|------|
| **ピクセル数** | 8×8 = 64ピクセル |
| **データサイズ** | 128 bytes (各ピクセル2 bytes) |
| **データ形式** | 符号付き12-bit (0.25℃/LSB) |
| **読取順序** | 左上→右下（行優先） |

### フレームレート

| 項目 | 仕様 |
|------|------|
| **設定値** | 10fps |
| **更新周期** | 100ms |
| **読取タイミング** | ポーリング or 割込 |

---

## レジスタマップ（主要）

| レジスタ | アドレス | 用途 |
|---------|---------|------|
| **PCLT** | 0x00 | 動作モード設定 |
| **RST** | 0x01 | リセット |
| **FPSC** | 0x02 | フレームレート設定 (10fps) |
| **INTC** | 0x03 | 割込設定 |
| **T01L-T64H** | 0x80-0xFF | 温度データ (64ピクセル × 2bytes) |

## 初期化シーケンス

```cpp
// 1. ソフトウェアリセット
I2C_Write(0x68, 0x01, 0x3F);
delay(50);

// 2. ノーマルモード設定
I2C_Write(0x68, 0x00, 0x00);

// 3. フレームレート 10fps 設定
I2C_Write(0x68, 0x02, 0x00);

// 4. 割込無効
I2C_Write(0x68, 0x03, 0x00);
```

---

## データ読取例

```cpp
// 64ピクセル温度読取
uint8_t data[128];
I2C_ReadBytes(0x68, 0x80, data, 128);

// 温度変換
for (int i = 0; i < 64; i++) {
  int16_t raw = (data[i*2+1] << 8) | data[i*2];
  float temp = raw * 0.25; // 0.25℃/LSB
  pixel_temps[i] = temp;
}
```
