## 概要

Pitchモーター（BLDCモーター）の角度検出用可変抵抗器。
YAWモーターと同様のBLDC制御を実現するため、RCサーボから変更。

**変更理由:**
- SimpleFOCによる高精度制御
- トルク・速度の柔軟な調整
- RCサーボのPWM制御からアナログ角度フィードバックへ移行

## Pitchモーター統合設計

### システム構成

```
[BLDCモーター（Pitch軸）]
    ↓
[可変抵抗器 RK0971210-F15-C0-B503]
    ↓（アナログ電圧出力）
[ESP32-S3 ADC入力]
    ↓
[SimpleFOC制御]
```

### 配線構成

| 端子 | 機能 | 接続先 |
|------|------|--------|
| **端子1** | 抵抗上端（VCC） | 3.3V |
| **端子2** | 出力（ワイパー） | ESP32-S3 ADC（GPIO1-GPIO10のいずれか） |
| **端子3** | 抵抗下端（GND） | GND |

### 角度検出原理

**電圧分割:**
```
V_out = V_CC × (θ / θ_max)

V_CC = 3.3V
θ_max = 300°

角度0°   → V_out = 0V
角度150° → V_out = 1.65V
角度300° → V_out = 3.3V
```

**ESP32-S3 ADC仕様:**
- 分解能: 12bit (0-4095)
- 入力電圧範囲: 0-3.3V
- 角度分解能: 300° / 4096 ≈ 0.073° ≈ 4.4分

## SimpleFOC制御パラメータ

### ADC読取とキャリブレーション

```cpp
// 可変抵抗ADC設定
#define VR_PIN GPIO10
#define VR_ADC_MAX 4095
#define VR_ANGLE_MAX 300.0  // degrees

// ADC読取
uint16_t adc_value = analogRead(VR_PIN);
float angle_deg = (adc_value / (float)VR_ADC_MAX) * VR_ANGLE_MAX;
float angle_rad = angle_deg * PI / 180.0;

// SimpleFOC角度センサー統合
class VariableResistorSensor : public Sensor {
public:
    float getAngle() override {
        uint16_t adc = analogRead(VR_PIN);
        return (adc / (float)VR_ADC_MAX) * VR_ANGLE_MAX * PI / 180.0;
    }
};
```

### キャリブレーション

**手順:**
1. Pitch軸を物理的に0°位置に移動
2. ADC値を読み取り → `adc_min`
3. Pitch軸を物理的に300°位置に移動
4. ADC値を読み取り → `adc_max`
5. 実測値で補正式を作成

```cpp
// キャリブレーション補正
float calibrated_angle = map(adc_value, adc_min, adc_max, 0, 300.0);
```

## 設計上の考慮点

### 利点

1. **高精度角度検出**
   - 12bit ADC: 0.073°分解能
   - AS5600（YAW）と同等の精度

2. **SimpleFOC統合**
   - YAWモーターと同じ制御アルゴリズム
   - PIDパラメータの共通化

3. **低コスト**
   - AS5600（磁気エンコーダー）不要
   - 可変抵抗のみで角度検出

4. **簡単な配線**
   - 3線（VCC, GND, OUT）
   - I2Cバス不要

### 制約・課題

1. **絶対角度制限**
   - 回転範囲: 300°（AS5600は360°）
   - 300°を超える回転は不可

2. **ノイズ対策**
   - アナログ電圧 → ESP32-S3 ADC
   - シールド線推奨（ツイストペア or 同軸）
   - グラウンドプレーン近接配線

3. **機械的寿命**
   - 回転寿命: 15,000回転以上
   - 頻繁な往復動作には不向き
   - YAWモーター（連続回転）とは異なる

4. **温度ドリフト**
   - 抵抗値温度係数による誤差
   - 定期的なキャリブレーション推奨

5. **取付精度**
   - モーター軸とのカップリング精度が重要
   - バックラッシュ最小化
