## 配線仕様

### ピン配置（3.5mm 4極）

```
    Tip
     │  ┌─ 24V電源
     ├─ │
     │  └─ Ring1
     ├─ ┌─ GND
     │  └─ Ring2
     ├─ ┌─ UART TX (Winch → HD)
     │  └─ Ring3
     └─ ┌─ UART RX (HD → Winch)
        └─ Sleeve
```

| ピン | 信号名 | 電圧 | 電流 |
|------|--------|------|------|
| **Tip** | 24V電源 | 24V | 最大 1.5A |
| **Ring1** | GND | 0V | 最大 1.5A |
| **Ring2** | UART TX | 3.3V | ~1mA |
| **Ring3 (Sleeve)** | UART RX | 3.3V | ~1mA |

---

## 接続経路

```
Winch (天井固定)
  ↓
Pulley (プーリー)
  ↓
Winch Female (4極ミニプラグ メス) - 着脱可能
  ↓
[Cable-4pole 両端オス 3m] ← この仕様書
  ↓
AS5600 (AS-S) - ケーブル回転角度測定
  ↓
Slip Ring (連続回転機構)
  ↓
HD (DCDC Converter入力)
```

## 電気特性

### 導体抵抗

| 項目 | 計算 |
|------|------|
| **AWG 30抵抗** | 約 338Ω/km |
| **3m抵抗** | 338Ω/km × 0.003km = 1.014Ω |
| **電圧降下 (1.5A)** | 1.5A × 1.014Ω = 1.52V |
| **HD入力電圧** | 24V - 1.52V = 22.48V |

**DCDC入力範囲:** 4.5-28V → 22.48V は許容範囲内 ✅

### UART信号伝送

| 項目 | 仕様 |
|------|------|
| **ボーレート** | 38400 baud |
| **信号電圧** | 3.3V (TTLレベル) |
| **ケーブル長** | 3m |
| **シールド** | なし |
| **ノイズ対策** | 低速通信のため不要 |

**伝送品質:**
- 38400 baud = 26μs/bit
- 3m ケーブルの遅延: ~15ns（無視できる）
- ノイズ: スリップリングブラシノイズ < UART耐性

## 代替仕様（検討）

### ケーブル太さアップグレード

| 項目 | AWG 30 | AWG 26 | AWG 24 |
|------|--------|--------|--------|
| **抵抗 (3m)** | 1.014Ω | 0.406Ω | 0.256Ω |
| **電圧降下 (1.5A)** | 1.52V | 0.61V | 0.38V |
| **HD入力電圧** | 22.48V | 23.39V | 23.62V |

**AWG 26推奨理由:**
- 電圧降下改善（1.52V → 0.61V）
- 柔軟性維持
- コスト増加は軽微
