## 搭載部品

| 部品 | 数量 | 用途 |
|------|------|------|
| **GridEye AMG8833** | 1個 | 赤外線アレイセンサー |

### CR Board (Compass Ring)

| 部品 | 数量 | 用途 |
|------|------|------|
| **GY-85** | 1個 | 9軸センサー (ADXL345 + ITG3205 + QMC5883L) |
| **NeoPixel WS2812B** | 48個 | 前面24 + 背面24 |

**制御マイコン:**
- **なし**（V1から変更）
- センサーとLEDのみ実装

## NeoPixel配置

### 配置パターン

| 基板 | 配置 |
|------|------|
| **GR前面** | 円形上に24個 |
| **GR背面** | 円形上に24個 |
| **CR前面** | 円形上に24個 |
| **CR背面** | 円形上に24個 |

**円周配置:**
- 等間隔配置（360° ÷ 24 = 15°間隔）
- 表裏対称配置

### カスケード接続

```
HD → NeoPixel Data
  ↓
GR 前面 (0-23)
  ↓
GR 背面 (24-47)
  ↓
CR 前面 (48-71)
  ↓
CR 背面 (72-95)
```

## 接続方式

### 電源・信号

| 信号 | GR | CR |
|------|----|----|
| **5V** | HD → PR → GR | HD → PR → CR |
| **GND** | HD → PR → GR | HD → PR → CR |
| **I2C0 (SDA/SCL)** | HD → PR → GridEye | - |
| **I2C1 (SDA/SCL)** | - | HD → PR → GY-85 |
| **NeoPixel Data** | HD → PR → GR → CR | GR → CR |

### PRからGR/CRへの配線

**配線方法:**
- 選択肢: フレキシブル基板 (FPC) / ハーネス / 直付け
