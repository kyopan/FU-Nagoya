## 基本仕様

| 項目 | 仕様 |
|------|------|
| **型番** | TPS54202DDCR |
| **メーカー** | Texas Instruments |
| **タイプ** | 同期整流降圧型DCDCコンバーター |
| **入力電圧範囲** | 4.5-28V |
| **出力電圧** | 5V (固定) |
| **最大出力電流** | 2A |
| **スイッチング周波数** | 500kHz |
| **効率** | 最大 95% |
| **パッケージ** | SOT-23-6 |

## 採用理由

| 項目 | 理由 |
|------|------|
| **入力電圧範囲** | 24V入力に対応（4.5-28V） |
| **出力電流** | 2A（NeoPixel 96個 + ESP32-S3 × 2に対応） |
| **スイッチング周波数** | 500kHz（ノイズ対策に有利） |
| **効率** | 高効率（発熱低減） |
| **小型** | SOT-23-6（基板面積削減） |

**候補比較:**

| 型番 | 出力電流 | 周波数 | 効率 | 採用 |
|------|---------|-------|------|------|
| LM2596 | 3A | 150kHz | 73% | ❌ 低効率 |
| MP1584 | 3A | 1.5MHz | 92% | ❌ ノイズ懸念 |
| XL4015 | 5A | 180kHz | 96% | ❌ 過剰容量 |
| **TPS54202DDCR** | **2A** | **500kHz** | **95%** | **✅ 採用** |

## 電流計算

### 負荷電流内訳

| 負荷 | 電流 |
|------|------|
| **NeoPixel 96個** | 1.73A (18mA × 96個) |
| **ESP32-S3 #1** | 120mA (WiFi動作時) |
| **ESP32-S3 #2** | 120mA (モーター制御時) |
| **GridEye** | 4.5mA |
| **GY-85** | 20mA |
| **AS5600 × 2** | 13mA (6.5mA × 2個) |
| **合計** | **2.0A** |

### 安全マージン

| 項目 | 計算 |
|------|------|
| **実負荷** | 2.0A |
| **DCDC容量** | 2.0A |
| **安全マージン** | 2.0A ÷ 2.0A = **1.0倍** |
| **推奨マージン** | 1.5倍 |

**⚠️ 懸念点:**
- 安全マージンが不足（1.0倍 < 1.5倍推奨）
- NeoPixel全点灯時に過負荷の可能性

**対策案:**
1. NeoPixel輝度制限（30% → 20%）
2. DCDC容量増（3A品への変更検討）
3. NeoPixel分離電源（別系統5V追加）

## 回路設計

### 基本回路

```
VIN (24V) ───┬─── L1 (4.7μH) ───┬─── VOUT (5V)
             │                   │
            C1 (10μF)           C2 (22μF)
             │                   │
            GND                 GND

TPS54202 接続:
- VIN: 24V入力
- SW: L1接続
- GND: グランド
- FB: 分圧抵抗（5V設定）
- EN: Enable (Highで動作)
- PG: Power Good出力
```

### 周辺部品

| 部品 | 値 | 用途 |
|------|-----|------|
| **L1** | 4.7μH (3A以上) | インダクタ |
| **C1** | 10μF (35V) | 入力コンデンサ |
| **C2** | 22μF (6.3V) × 2 | 出力コンデンサ |
| **R1** | 10kΩ | フィードバック上側 |
| **R2** | 2.2kΩ | フィードバック下側 |
| **C3** | 100nF (セラミック) | バイパスコンデンサ |

## スイッチング周波数

| 項目 | 仕様 |
|------|------|
| **周波数** | 500kHz |
| **ノイズ帯域** | 500kHz ± 数十kHz |
| **対策** | センサー系とのグランド分離 |

**ノイズ対策:**
- I2C/UART通信ラインとDCDC出力を物理的に分離
- GNDプレーン分離（アナログGND / デジタルGND）
- フェライトビーズ追加検討

---

## 熱設計

| 項目 | 計算 |
|------|------|
| **入力電力** | 24V × 2.0A ÷ 0.95 = 50.5W |
| **出力電力** | 5V × 2.0A = 10W |
| **損失** | 50.5W - 10W = 40.5W |
| **効率** | 10W ÷ 50.5W = 19.8% |

**⚠️ 計算ミス修正:**

正しい計算:
```
入力電力 = 出力電力 ÷ 効率
         = 10W ÷ 0.95
         = 10.53W

損失 = 入力電力 - 出力電力
     = 10.53W - 10W
     = 0.53W
```

**発熱対策:**
- SOT-23-6パッケージは放熱面積小
- 基板銅箔面積で放熱
- サーマルビア配置

## レイアウト設計

### 推奨配置

```
[VIN] → [C1] → [TPS54202] → [L1] → [C2] → [VOUT]
                    ↓
                  [GND]
```

### 注意点

| 項目 | 推奨 |
|------|------|
| **C1配置** | TPS54202直近（5mm以内） |
| **C2配置** | 出力端子直近（10mm以内） |
| **L1配置** | ノイズ源から離す |
| **GND** | ベタグランド推奨 |
| **配線幅** | VIN/VOUT: 0.5mm以上 |
