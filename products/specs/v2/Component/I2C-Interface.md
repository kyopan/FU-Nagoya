## I2Cバス構成

### I2C0系統

| 項目 | 仕様 |
|------|------|
| **マスター** | ESP32-S3 #1 |
| **スレーブ** | GridEye AMG8833 (GR) |
| **I2Cアドレス** | 0x68 |
| **用途** | 赤外線アレイセンサーデータ取得 |

**接続経路:**
```
HD (ESP32-S3 #1) → PR取付機構 → GR Board → GridEye (0x68)
  ↓
I2C0 (SDA/SCL)
```

### I2C1系統

| 項目 | 仕様 |
|------|------|
| **マスター** | ESP32-S3 #1 |
| **スレーブ** | GY-85 (ADXL345, ITG3205, QMC5883L) |
| **I2Cアドレス** | 0x53 (ADXL345)<br/>0x68 (ITG3205)<br/>0x0D (QMC5883L) |
| **用途** | 9軸センサーデータ取得 |

**接続経路:**
```
HD (ESP32-S3 #1) → PR取付機構 → CR Board → GY-85
  ↓
I2C1 (SDA/SCL)
```

### I2C (ESP32-S3 #2用)

| 項目 | 仕様 |
|------|------|
| **マスター** | ESP32-S3 #2 |
| **スレーブ** | AS5600 × 2 (AS-S, AS-Y) |
| **I2Cアドレス** | 0x36 (両方とも) |
| **用途** | エンコーダー角度読取 |

**接続経路:**
```
ESP32-S3 #2 → AS5600 (AS-S) - スリップリング角度
            → AS5600 (AS-Y) - YAWモーター角度
```

**アドレス競合対策:**
- AS-S と AS-Y は**別々のI2Cバス**に接続（ESP32-S3 #2で2系統使用）

## クロック周波数

| モード | 周波数 | 選択 |
|--------|--------|------|
| **標準モード** | 100kHz | ✅ 採用 |
| **高速モード** | 400kHz | - |
| **高速モードPlus** | 1MHz | - |

**採用理由:**
- バス長15cm程度 → 100kHzで安定動作
- センサーデータレート（10fps, 1kHz等）に対して十分
- ノイズマージン確保

## プルアップ抵抗

### ESP32-S3内部プルアップ使用

| 項目 | 仕様 |
|------|------|
| **抵抗値** | 約 45kΩ (ESP32-S3内部) |
| **設定** | ソフトウェアで有効化 |
| **外部抵抗** | 不要（初期設定） |

```cpp
// ESP32-S3 内部プルアップ有効化
Wire.begin(SDA_PIN, SCL_PIN);
pinMode(SDA_PIN, INPUT_PULLUP);
pinMode(SCL_PIN, INPUT_PULLUP);
```

### 外部プルアップ（必要に応じて）

| 抵抗値 | 用途 |
|--------|------|
| **2.2kΩ** | 高速通信・長距離バス |
| **4.7kΩ** | 標準的な用途 |
| **10kΩ** | 低速通信・短距離バス |

**追加条件:**
- バス長 > 30cm
- スレーブ数 > 3個
- ノイズ環境下

- [ ] 実機テストで内部プルアップの動作確認

## バス長とキャパシタンス

### バス長の影響

| バス長 | キャパシタンス (推定) | 100kHz動作 |
|--------|----------------------|-----------|
| **5cm** | ~10pF | ✅ 良好 |
| **15cm** | ~30pF | ✅ 良好 |
| **30cm** | ~60pF | ⚠️ 注意 |
| **50cm** | ~100pF | ❌ 推奨外 |

**V2での最大バス長:**
- HD → PR → GR/CR: 約15cm
- キャパシタンス: ~30pF → 100kHzで問題なし

## I2C通信フォーマット

### アドレス指定

```
START → [ADDR|R/W] → ACK → [DATA] → ACK → ... → STOP
```

| 項目 | ビット長 |
|------|---------|
| **スレーブアドレス** | 7-bit |
| **R/W bit** | 1-bit (0=Write, 1=Read) |
| **データ** | 8-bit |

### 例: GridEye温度読取

```cpp
// 0x68: GridEye アドレス
// 0x80: 温度データレジスタ開始アドレス

Wire.beginTransmission(0x68);
Wire.write(0x80);           // レジスタ指定
Wire.endTransmission(false); // リピートスタート
Wire.requestFrom(0x68, 128); // 128 bytes 読取

uint8_t data[128];
for (int i = 0; i < 128; i++) {
  data[i] = Wire.read();
}
```

## エラー処理

### ACK/NACK処理

```cpp
uint8_t error = Wire.endTransmission();

if (error == 0) {
  // 成功
} else if (error == 2) {
  // スレーブアドレス NACK
  Serial.println("Device not found");
} else if (error == 3) {
  // データ NACK
  Serial.println("Data transmission failed");
}
```

### タイムアウト設定

```cpp
Wire.setTimeout(100); // 100ms タイムアウト
```
