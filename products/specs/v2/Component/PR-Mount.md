**作成日**: 2025-11-09

## 基本仕様

| 項目 | 仕様 |
|------|------|
| **正式名称** | PR取付機構 (Pitch Ring Mount) |
| **役割** | HD → GR/CR への配線・固定機構 |
| **配線方式** | FPC (Flexible Printed Circuit) 推奨 |
| **コネクタ** | AFA07-S10FCC-00 |
| **固定方法** | サーボホーン経由でGR/CRを固定 |

---

## 配線仕様

### HD → PR配線 (5線系統)

| 信号 | 電圧 | 電流 | 用途 |
|------|------|------|------|
| **5V** | 5V | 2A | 電源供給 (NeoPixel + センサー) |
| **GND** | 0V | 2A | グランド |
| **I2C0 SDA** | 3.3V | - | GridEye (GR) データ |
| **I2C0 SCL** | 3.3V | - | GridEye (GR) クロック |
| **I2C1 SDA** | 3.3V | - | GY-85 (CR) データ |
| **I2C1 SCL** | 3.3V | - | GY-85 (CR) クロック |
| **NeoPixel Data** | 3.3V | - | LED制御信号 |

**合計: 7線 → 10pin FPC (予備含む)**

## 配線構成

### HD側

```
HD Board (ESP32-S3 #1)
  ↓
FPC コネクタ (AFA07-S10FCC-00)
  ↓
FPC ケーブル (10pin)
```

### PR側

```
FPC ケーブル (10pin)
  ↓
PR取付機構 (中継基板 or 直接接続)
  ↓
GR Board (I2C0 + NeoPixel Data + 5V/GND)
  ↓
CR Board (I2C1 + NeoPixel Data + 5V/GND)
```

---

## PR取付機構設計

### 機能

| 項目 | 仕様 |
|------|------|
| **電気的役割** | HD → GR/CR 信号中継 |
| **機械的役割** | GR/CRの固定・Pitch軸回転 |
| **駆動** | RCサーボ (HD搭載) のサーボホーン経由 |

### 構造（推定）

```
    [HD Board]
        ↓
    [FPC ケーブル]
        ↓
  [PR取付機構]
    /        \
  GR        CR
 (前面)    (背面)
```

**サーボ接続:**
- サーボ本体: HD基板に固定
- サーボホーン: PR取付機構に接続
- Pitch軸回転: サーボホーンの回転 → PR取付機構が傾く → GR/CRが傾く

## I2Cプルアップ抵抗配置

**候補:**
1. **HD側配置** (推奨)
   - ESP32-S3内部プルアップ使用
   - 外部抵抗不要

2. **PR側配置**
   - 外付けプルアップ抵抗 (2.2kΩ or 4.7kΩ)
   - PR取付機構に実装

**決定:**
- [ ] HD側 or PR側 選定
- ESP32-S3内部プルアップで動作確認後、必要に応じてPR側に追加

## NeoPixelシグナルインテグリティ対策

### ノイズ対策

| 項目 | 対策 |
|------|------|
| **信号線長** | 最大30cm (HD → GR → CR) |
| **データレート** | 400kHz |
| **対策** | なし（現状） |

**必要に応じて:**
- データ線バッファIC (74HCT245等) 追加
- FPC GND強化
- データ線とGNDのツイストペア配線

**決定事項:**
