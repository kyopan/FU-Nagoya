# GY-85 9軸センサー仕様書

**作成日**: 2025-11-09
**ステータス**: ✅ 確定

---

## 基本仕様

| 項目 | 仕様 |
|------|------|
| **モジュール名** | GY-85 |
| **構成センサー** | ADXL345 (加速度) + ITG3205 (ジャイロ) + QMC5883L (磁気) |
| **軸数** | 9軸 (加速度3軸 + ジャイロ3軸 + 磁気3軸) |
| **インターフェース** | I2C |
| **動作電圧** | 3.0-5.5V |
| **消費電流** | 約 20mA |

---

## 構成センサー詳細

### ADXL345 (加速度センサー)

| 項目 | 仕様 |
|------|------|
| **軸数** | 3軸 (X, Y, Z) |
| **測定範囲** | ±2g / ±4g / ±8g / ±16g (設定可能) |
| **分解能** | 13-bit |
| **I2Cアドレス** | 0x53 |
| **サンプリングレート** | 最大 3200Hz |

### ITG3205 (ジャイロセンサー)

| 項目 | 仕様 |
|------|------|
| **軸数** | 3軸 (X, Y, Z) |
| **測定範囲** | ±2000°/s |
| **分解能** | 16-bit |
| **I2Cアドレス** | 0x68 |
| **サンプリングレート** | 最大 8kHz (内部), 出力 1kHz |

### QMC5883L (磁気センサー)

| 項目 | 仕様 |
|------|------|
| **軸数** | 3軸 (X, Y, Z) |
| **測定範囲** | ±8 Gauss |
| **分解能** | 16-bit |
| **I2Cアドレス** | 0x0D |
| **サンプリングレート** | 10-200Hz |

**注:** V1では HMC5883L を使用していたが、V2では QMC5883L に変更

## 配置

|------|------|
| **実装基板** | CR Board (Compass Ring 背面) |
| **向き** | 背面（展示空間後方） |
| **用途** | 姿勢検出 / 方位測定 / 加速度検出 |

## I2C通信仕様

| 項目 | 仕様 |
|------|------|
| **I2Cバス** | I2C1系統 (HD ESP32-S3 #1) |
| **クロック周波数** | 100kHz |
| **プルアップ抵抗** | ESP32-S3内部プルアップ使用 |
| **バス長** | 最大15cm程度 (HD → PR → CR) |

**I2Cアドレス一覧:**

| センサー | I2Cアドレス |
|---------|------------|
| ADXL345 | 0x53 |
| ITG3205 | 0x68 |
| QMC5883L | 0x0D |

**接続経路:**
```
HD (ESP32-S3 #1) → PR取付機構 → CR Board → GY-85
  ↓
I2C1 (SDA/SCL)
```

## 磁気センサー較正

| 項目 | 仕様 |
|------|------|
| **較正方法** | 使用しない |
| **理由** | 方位測定が主目的ではない |
| **用途** | 相対的な磁気変化検出のみ |

## データ読取例

### ADXL345 (加速度)

```cpp
// 加速度データ読取
int16_t accel_x = I2C_Read16(0x53, 0x32); // DATAX0, DATAX1
int16_t accel_y = I2C_Read16(0x53, 0x34); // DATAY0, DATAY1
int16_t accel_z = I2C_Read16(0x53, 0x36); // DATAZ0, DATAZ1

// ±2g 設定時の変換
float accel_x_g = accel_x * 0.004; // 3.9mg/LSB
```

### ITG3205 (ジャイロ)

```cpp
// ジャイロデータ読取
int16_t gyro_x = I2C_Read16(0x68, 0x1D); // GYRO_XOUT_H, GYRO_XOUT_L
int16_t gyro_y = I2C_Read16(0x68, 0x1F); // GYRO_YOUT_H, GYRO_YOUT_L
int16_t gyro_z = I2C_Read16(0x68, 0x21); // GYRO_ZOUT_H, GYRO_ZOUT_L

// 角速度変換
float gyro_x_dps = gyro_x / 14.375; // 14.375 LSB/(°/s)
```

### QMC5883L (磁気)

```cpp
// 磁気データ読取
int16_t mag_x = I2C_Read16(0x0D, 0x00); // Data Output X LSB, MSB
int16_t mag_y = I2C_Read16(0x0D, 0x02); // Data Output Y LSB, MSB
int16_t mag_z = I2C_Read16(0x0D, 0x04); // Data Output Z LSB, MSB
```

## 用途

| センサー | 用途 |
|---------|------|
| **ADXL345** | 傾き検出 / 振動検出 / 衝撃検知 |
| **ITG3205** | 回転速度測定 / ジャイロドリフト補正 |
| **QMC5883L** | 磁気変化検出（較正なし） |
