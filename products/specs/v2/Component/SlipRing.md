## AS5600エンコーダー配置

| 項目 | 仕様 |
|------|------|
| **配置場所** | スリップリング上部（4極ミニプラグ メス側） |
| **測定対象** | ケーブル相対回転角度 (0-360°) |
| **用途** | ケーブルねじれ検出 → YAWモーター補正 |
| **エンコーダー型番** | AS5600 (AS-S) |
| **磁石** | 4mm × 3mm ネオジム磁石 |

**配置構造:**
```
Winch ケーブル (4極ミニプラグ オス)
  ↓
AS5600 (AS-S) - ケーブル回転角度測定
  ↓
スリップリング 連続回転機構
  ↓
4極ミニプラグ メス (HD側へ)
```

## 電気特性

### 導通抵抗

| 項目 | 仕様 |
|------|------|
| **抵抗値** | 10mΩ / 線 |
| **電圧降下 (1.5A時)** | 1.5A × 10mΩ = 15mV |
| **電力損失 (1.5A時)** | 1.5A² × 10mΩ = 22.5mW |

**24V電源の電圧降下影響:**
- 24V - 15mV = 23.985V（影響ほぼなし）

### ノイズ特性

| 項目 | 仕様 |
|------|------|
| **ブラシノイズ** | あり（回転時） |
| **UART影響** | 低速（38400 baud）のため影響小 |
| **対策** | 不要（現状） |

## 制御ロジック

### ケーブルねじれ検出

```cpp
// AS5600 (AS-S) 読取
uint16_t cable_angle = AS5600_ReadAngle(AS_S_ADDRESS); // 0-4095

// 角度変換
float cable_rotation = cable_angle * (360.0 / 4096.0); // 0-360°

// ねじれ判定（±90°以上）
if (abs(cable_rotation - 180.0) > 90.0) {
  // YAWモーター逆回転で補正
  apply_yaw_correction(cable_rotation);
}
```
