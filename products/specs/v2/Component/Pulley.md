## ディスクスプール方式

### 構造

```
     [モーター/手動]
           ↓
    ┌─────────┐
    │         │  ← ディスク（直径120mm）
    │    ●    │
    │         │
    └─────────┘
          ↓
      [ケーブル]
```

**特徴:**
- ケーブルがディスク表面に巻き付く
- 巻取長さ = 円周 × 巻数
- スプール方式より省スペース

### 巻取能力計算

| 項目 | 計算 |
|------|------|
| **円周** | π × 120mm = 377mm |
| **1周あたり長さ** | 377mm |
| **10周巻取** | 377mm × 10 = 3.77m |
| **20周巻取** | 377mm × 20 = 7.54m |

**ケーブル太さ影響:**
- AWG 30 外径: 約 3mm
- 10周積層高さ: 3mm × 10 = 30mm

## 材質検討

### 樹脂製

| 項目 | 評価 |
|------|------|
| **メリット** | 軽量・加工容易・低コスト |
| **デメリット** | 強度不足・摩耗 |
| **適用** | 軽負荷・短期展示 |

### アルミ製

| 項目 | 評価 |
|------|------|
| **メリット** | 高強度・耐久性高 |
| **デメリット** | 重量増・加工コスト高 |
| **適用** | 長期展示・高負荷 |
