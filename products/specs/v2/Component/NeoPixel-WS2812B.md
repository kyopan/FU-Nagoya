## 基本仕様

| 項目 | 仕様 |
|------|------|
| **型番** | WS2812B 2020 |
| **パッケージ** | 2.0mm × 2.0mm SMD |
| **色** | RGB (フルカラー) |
| **制御IC** | 内蔵 |
| **通信方式** | シリアル (1-wire) |
| **動作電圧** | 5V |
| **データ信号電圧** | 3.3V対応（ESP32直接接続可能） |
| **1個あたり最大電流** | 60mA (RGB全点灯時) |
| **想定輝度電流** | 18mA (30%輝度想定) |

|------|------|------|----------|

| **CR (Compass Ring)** | 24個 | 24個 | 48個 |
| **総数** | - | - | **96個** |

## 電源仕様

| 項目 | 計算 | 値 |
|------|------|-----|
| **1個あたり電流** | 30%輝度想定 | 18mA |
| **96個合計電流** | 18mA × 96個 | 1.73A |
| **電源電圧** | DCDC 5V出力 | 5V |
| **安全マージン** | 1.5倍 | 2.6A (DCDC容量) |

**DCDC出力:**
- TPS54202DDCR: 2A出力
- 安全マージン: 2A ÷ 1.73A = 1.16倍（やや余裕不足）

**検討事項:**
- [ ] 全点灯時の電流測定
- [ ] DCDC容量再検討（3A品への変更検討）

## データ線仕様

| 項目 | 仕様 |
|------|------|
| **信号電圧** | 3.3V (ESP32出力) |
| **レベルシフター** | 不使用（5V電源でも3.3V信号で動作） |
| **最大信号線長** | 30cm (HD → GR → CR) |
| **リフレッシュレート** | 400kHz |
| **データ線バッファIC** | 不使用 |

**信号経路:**
```
HD (ESP32-S3 #1) → PR取付機構 → GR (48個) → CR (48個)
  ↓
NeoPixel Data (シリアル信号)
```

## タイミング仕様

| 項目 | 仕様 |
|------|------|
| **T0H** | 0.4μs ±0.15μs |
| **T0L** | 0.85μs ±0.15μs |
| **T1H** | 0.8μs ±0.15μs |
| **T1L** | 0.45μs ±0.15μs |
| **RES** | >50μs (リセット) |

**クロック周波数:**
- 400kHz → 2.5μs/bit
- 96個 × 24bit = 2304bit
- 1フレーム更新時間: 2304bit × 2.5μs = 5.76ms
- 最大フレームレート: 1 / 5.76ms = 173fps

## 制御方式

### 色指定フォーマット

```cpp
// GRB順（WS2812B仕様）
uint8_t led_data[96][3];

// 例: LED 0番を赤色に設定
led_data[0][0] = 0;    // Green
led_data[0][1] = 255;  // Red
led_data[0][2] = 0;    // Blue
```

### カスケード接続

```cpp
// HD → GR (0-47) → CR (48-95)
// 96個連続送信

for (int i = 0; i < 96; i++) {
  send_pixel(led_data[i][0], led_data[i][1], led_data[i][2]);
}
send_reset(); // >50μs LOW
```

## 配線設計

| 項目 | 仕様 |
|------|------|
| **5V電源ライン** | AWG 20-22 (太線推奨) |
| **GNDライン** | AWG 20-22 (太線推奨) |
| **データライン** | AWG 26-30 (細線可) |
