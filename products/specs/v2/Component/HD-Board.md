## 実装レイアウト

### 配置方針

```
        [北]
         ↑
         │
    ┌────────┐
    │        │
[西]│   ●    │[東] ← サーボ: 右端（東側）
    │        │      未定部品: 左端（西側）
    └────────┘
         │
         ↓
       [南]
    YAWモーター
```

### サーボ配置

| 項目 | 仕様 |
|------|------|
| **位置** | HD右端（東側） |
| **向き** | サーボ軸が南向き（YAWモーター側） |
| **取付** | ネジ固定 or 基板穴固定 |

- DCDC Converter (TPS54202)

- FPC コネクタ

## 層構成（4層）

| 層 | 用途 | 特記事項 |
|----|------|----------|
| **L1 (Top)** | 信号・部品実装面 | 高密度配線 |
| **L2 (Inner)** | GND プレーン | ノイズシールド |
| **L3 (Inner)** | 電源プレーン (5V/3.3V) | 低インピーダンス |
| **L4 (Bottom)** | 信号・GND補強 | 部品実装可 |

**プレーン分割:**
- L2: アナログGND / デジタルGND 分離
- L3: 5V / 3.3V / 24V 分離

## 電源系統

### 電源フロー

```
24V (Winch) → DCDC (TPS54202) → 5V → LDO → 3.3V (ESP32-S3 × 2)
                                  ↓
                                NeoPixel (5V直接)
                                  ↓
                                RCサーボ (要検討: 5V or 3.7V)
```

### 電源レール

| レール | 電圧 | 電流 | 用途 |
|--------|------|------|------|
| **24V** | 24V | 1.5A | DCDC入力 |
| **5V** | 5V | 2A | NeoPixel / サーボ / LDO入力 |
| **3.3V** | 3.3V | 500mA | ESP32-S3 × 2 / センサー |

## 信号系統

### I2C

| バス | 用途 | SDA | SCL |
|------|------|-----|-----|
| **I2C0** | GridEye (GR) | GPIO未定 | GPIO未定 |
| **I2C1** | GY-85 (CR) | GPIO未定 | GPIO未定 |
| **I2C (ESP32-S3 #2)** | AS5600 × 2 | GPIO未定 | GPIO未定 |

### UART

| 信号 | 用途 | GPIO |
|------|------|------|
| **TX** | HD → Winch | GPIO未定 |
| **RX** | Winch → HD | GPIO未定 |

### PWM

| 信号 | 用途 | GPIO |
|------|------|------|
| **Servo PWM** | RCサーボ制御 | GPIO未定 |
| **BLDC PWM × 3** | DRV8311 (U/V/W) | GPIO未定 × 3 |

### NeoPixel

| 信号 | 用途 | GPIO |
|------|------|------|
| **Data** | NeoPixel 96個制御 | GPIO未定 |

## FPC接続仕様

### HD → PR配線 (5線)

| 信号 | 電圧 | 電流 |
|------|------|------|
| 5V | 5V | 2A |
| GND | 0V | 2A |
| I2C0 SDA | 3.3V | - |
| I2C0 SCL | 3.3V | - |
| I2C1 SDA | 3.3V | - |
| I2C1 SCL | 3.3V | - |
| NeoPixel Data | 3.3V | - |

**コネクタ候補:**
- AFA07-S10FCC-00 (FPC 10pin)

## 熱設計

### 発熱源

| 部品 | 発熱量 (推定) |
|------|--------------|
| **TPS54202** | 0.5W |
| **DRV8311** | 1.0W |
| **ESP32-S3 × 2** | 0.5W × 2 = 1.0W |
| **合計** | 2.5W |

### 放熱対策

| 項目 | 仕様 |
|------|------|
| **銅箔面積** | 最大化（L2 GNDプレーン） |
| **サーマルビア** | 発熱部品下に配置 |
| **エアフロー** | 自然対流 |
