### 1.0mm線の特性

| 項目 | 計算値 |
|------|--------|
| **断面積** | π × (0.5mm)² = 0.785 mm² |
| **1本あたり引張荷重** | 0.785mm² × 300MPa = 235.5 N ≈ 24 kgf |
| **6本合計** | 1,413 N ≈ 144 kgf |

**安全率:**
- GR/CR重量: 未測定（推定 < 500g）
- 安全率: 144 kgf / 0.5 kgf = **288倍** ✅ 十分

## 電気的特性

**導電性**: 真鍮は導電性材料

| 項目 | 値 |
|------|-----|
| **導電率** | 約28% IACS（銅の28%） |
| **抵抗率** | 約6.2 × 10⁻⁸ Ω·m |
| **300mm線の抵抗** | R = ρL/A = 6.2×10⁻⁸ × 0.3 / 0.785×10⁻⁶ = **0.024 Ω** |

**注意:**
- 真鍮線は電気的導通路として使用**しない**
- あくまで機械的固定のみ
- 電気信号はFPC/ハーネス経由

## 設計考慮事項

### 配線との干渉

**信号線配置:**
- FPC: HD → PR → GR/CR（5V/GND/I2C0/I2C1/NeoPixel）
- 真鍮線: PR → GR/CR固定用

**干渉回避:**
- 真鍮線とFPCの物理的分離
- 真鍮線による電磁ノイズ影響は軽微（信号3.3V、低周波）

### 振動・応力

**使用環境:**
- Pitchサーボによる傾き: ±30°（推定）
- YAWモーター回転: 連続回転
- 加速度: 未測定

**応力解析:**
- 静的荷重: GR/CR重量（< 500g）
- 動的荷重: 回転・傾きによる慣性力
- 安全率288倍により十分な余裕 ✅
