# AS5600 磁気エンコーダー仕様書

**作成日**: 2025-11-09
**ステータス**: ✅ 確定

---

## 基本仕様

| 項目 | 仕様 |
|------|------|
| **型番** | AS5600 |
| **タイプ** | 12-bit磁気ロータリーポジションセンサー |
| **分解能** | 12-bit (4096段階) |
| **角度範囲** | 0-360° (連続回転対応) |
| **インターフェース** | I2C |
| **I2Cアドレス** | 0x36 (固定) |
| **動作電圧** | 3.0-5.5V |
| **消費電流** | 6.5mA (typ.) |

---

## 使用箇所

### AS-S (Slip Ring Encoder)

| 項目 | 仕様 |
|------|------|
| **配置場所** | スリップリング上部（4極ミニプラグ メス側） |
| **測定対象** | ケーブル相対回転角度 |
| **用途** | ケーブルねじれ検出 → YAWモーター補正 |
| **接続先** | ESP32-S3 #2 (I2C) |

### AS-Y (YAW Encoder)

| 項目 | 仕様 |
|------|------|
| **配置場所** | YAWモーター軸 |
| **測定対象** | YAWモーター回転角度 |
| **用途** | SimpleFOC制御フィードバック |
| **接続先** | ESP32-S3 #2 (I2C) |

**合計使用数**: 2個

## I2C通信仕様

| 項目 | 仕様 |
|------|------|
| **I2Cアドレス** | 0x36 (変更不要) |
| **クロック周波数** | 100kHz |
| **プルアップ抵抗** | ESP32-S3内部プルアップ使用 |
| **バス長** | 最大15cm程度 |

**アドレス競合対策:**
- AS-S (0x36) と AS-Y (0x36) は**別々のI2Cバス**に接続
- ESP32-S3 #2 で2系統のI2Cを使用

## 制御ロジック

### AS-S (ケーブルねじれ検出)

```cpp
// ケーブル角度読取
uint16_t cable_angle = AS5600_ReadAngle(AS_S_ADDRESS);

// ねじれ補正判定
if (abs(cable_angle - 180) > THRESHOLD) {
  // YAWモーター逆回転でケーブル巻き戻し
  apply_yaw_correction(cable_angle);
}
```

### AS-Y (YAWモーターフィードバック)

```cpp
// SimpleFOC用エンコーダー値
float yaw_angle = AS5600_ReadAngle(AS_Y_ADDRESS) * (360.0 / 4096.0);
motor.move(target_angle);
```

## レジスタマップ（主要）

| レジスタ | アドレス | 用途 |
|---------|---------|------|
| **RAW ANGLE** | 0x0C-0x0D | 生角度値 (0-4095) |
| **ANGLE** | 0x0E-0x0F | フィルタ後角度値 |
| **STATUS** | 0x0B | 磁石検出状態 |
| **AGC** | 0x1A | 自動ゲイン制御 |
