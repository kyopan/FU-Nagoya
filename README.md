## 概要

**会場**: Common Nexus（ComoNe）

46個（または16個）の筒状ロボットが天井から吊り下げられ、ダクトレールシステムで制御されるインタラクティブ・インスタレーション。各ロボットは来場者を感知し、群としての振る舞いと個としての個性を表現します。言語を持たないロボットたちが、動きや光によって来場者とコミュニケーションを図ります。

米澤拓郎教授（名古屋大学）の「共有リアリティ」研究と連携し、異なる現実をつなぐインターリアリティを探求します。

## 目的

- 群行動の中に見える個性の表現
- 非言語コミュニケーションの探求
- インターリアリティ研究の実践
- 来場者とロボット群の相互作用の創出

## 主要機能

- Grid-EYE（8×8サーマルセンサー）による来場者検知
- マイクアレイによる空間トラッキング
- ダクトレール上の位置制御システム
- ポジティブ/ネガティブフィードバックループによる群行動
- 各ロボットの個性パラメータ設定
