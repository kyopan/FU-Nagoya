## 🎯 目的

FU@ComoNeプロジェクトにおける筒ロボット制御用ウィンチシステムV2の回路設計仕様を定義する。

**V2の設計方針**: V1で実証した機能を維持しつつ、基板統合・構造シンプル化・コスト削減・メンテナンス性向上を実現

## 📊 プロジェクト概要

| 項目 | 内容 |
|------|------|
| **台数** | 60台（本番46台 + 予備14台） |
| **設置場所** | Common Nexus（ComoNe）天井・照明用ダクトレール固定 |
| **制御対象** | 筒ロボット（垂直昇降、最大3メートル） |
| **通信** | 筒基板との双方向通信（24V電源 + UART） |
| **V1実績** | 動作実証完了、7枚基板構成の簡素化が必要 |
| **制御可能台数** | 最大128台（Wi-Fi経由） |

## 📐 回路構成

### ブロック図

```
[AC100V/DC24V] → [電源回路] → [24V出力]
                      ↓
              [マイコン(ESP32/Arduino)]
                      ↓
          ┌───────────┼───────────┐
          ↓           ↓           ↓
    [モータードライバ] [通信回路] [センサー入力]
          ↓           ↓
      [モーター]   [筒基板]
                  (ステレオ4極)
```

### 主要回路

#### 1. 電源回路
- AC100V → DC24V 変換（AC-DCコンバータ）
- または DC24V入力（外部電源）
- 24V → 5V/3.3V 降圧（マイコン用）
- 逆接続保護ダイオード
- 過電流保護ヒューズ

#### 2. マイコン回路
- ESP32-S3 or Arduino
- クリスタル発振子
- リセット回路
- デバッグ用UART
- GPIO保護回路

#### 3. モーター制御回路
- モータードライバIC
- PWM入力
- 電流センシング（オプション）
- 逆起電力保護

#### 4. 通信回路
- UART → ステレオ4極ジャック
- ESD保護回路（TX/RX）
- プルアップ/プルダウン抵抗
- 24V電源供給ライン

#### 5. センサー入力回路
- リミットスイッチ × 2（上限/下限）
- プルアップ抵抗
- ノイズフィルタ

## 📝 設計メモ

### V1の構造（参考）
- **基板構成**: 7枚構成（複雑）
- **スリップリング**: 回転給電・通信用
- **電源変換**: AC100V → DC24V/5V 内蔵
- **通信方式**: RS485（ノイズ耐性）
- **モーター**: 低騒音ステッピングモーター
- **非常ブレーキ**: ソレノイド式

### V2への主要改良点（優先度順）

#### 🔴 優先度: Critical
- [ ] **基板統合**: 7枚 → **2-3枚に削減**
  - 組立工数削減、故障箇所特定容易化
  - モジュール化による段階的製造可能

- [ ] **通信簡素化**: RS485 → **UART**
  - 配線削減（4線: GND, 24V, TX, RX）
  - ESD保護回路必須

- [ ] **スリップリング簡素化**
  - 接点数最小化（電源 + 通信のみ）
  - 長寿命材質選定

#### 🟡 優先度: High
- [ ] **電源統一検討**: AC100V → **DC24V入力**のみ
  - AC-DC変換回路削除でコスト削減
  - 安全性向上（低電圧化）

- [ ] **ソレノイドブレーキ代替**
  - 電気的ブレーキ方式の検討
  - コスト・重量削減

- [ ] **コネクタ脱落防止強化**
  - ステレオ4極ジャック固定機構
  - 磁石コネクタ採用範囲拡大

#### 🟢 優先度: Medium
- [ ] エンコーダー追加検討（位置精度向上）
- [ ] 電流センサー追加（予防保全）
- [ ] 基板サイズ最適化

### 検討事項
- [x] **モーター種別**: ステッピングモーター（V1実績継承）
- [x] **親機通信方式**: Wi-Fi（V1実績継承、128台制御可能）
- [ ] エンコーダーの必要性: オプション検討
- [ ] 筒重量の最終確定: 評価ボードテスト後
- [x] ケーブル長: 最大3メートル（V1実績）

### リスク & 対策
| リスク | 影響 | V1での対策 | V2での対策 |
|--------|------|-----------|-----------|
| **ケーブル断線** | 通信/給電断 | 3メートル制限 | **耐久テスト1ヶ月**（評価ボード） |
| **スリップリング摩耗** | 接触不良 | 定期メンテナンス | 長寿命材質、接点数削減 |
| **電源ノイズ** | 通信エラー | RS485採用 | **ESD保護回路必須**（UART） |
| **モーター過熱** | 動作停止 | 低騒音モーター | 温度監視オプション検討 |
| **7枚基板複雑性** | メンテナンス困難 | - | **2-3枚に統合** |

### V1で成功した点（V2で継承）
- ✅ Wi-Fi通信（最大128台制御）
- ✅ 低騒音ステッピングモーター
- ✅ 赤外線式位置検知センサー
- ✅ 5Wスポットライト
- ✅ ダクトレール固定方式
- ✅ スリップリング回転給電（簡素化して継承）
