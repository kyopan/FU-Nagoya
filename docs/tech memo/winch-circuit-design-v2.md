## 🎯 目的

FU@ComoNeプロジェクトにおける筒ロボット制御用ウィンチシステムの回路設計仕様を定義する。

## 📊 プロジェクト概要

| 項目 | 内容 |
|------|------|
| **台数** | 60台（本番46台 + 予備14台） |
| **設置場所** | Common Nexus（ComoNe）天井 |
| **制御対象** | 筒ロボット（垂直昇降） |
| **通信** | 筒基板との双方向通信（24V電源 + データ） |

## 📐 回路構成

### ブロック図

```
[AC100V/DC24V] → [電源回路] → [24V出力]
                      ↓
              [マイコン(ESP32/Arduino)]
                      ↓
          ┌───────────┼───────────┐
          ↓           ↓           ↓
    [モータードライバ] [通信回路] [センサー入力]
          ↓           ↓
      [モーター]   [筒基板]
                  (ステレオ4極)
```

### 主要回路

#### 1. 電源回路
- AC100V → DC24V 変換（AC-DCコンバータ）
- または DC24V入力（外部電源）
- 24V → 5V/3.3V 降圧（マイコン用）
- 逆接続保護ダイオード
- 過電流保護ヒューズ

#### 2. マイコン回路
- ESP32-S3 or Arduino
- クリスタル発振子
- リセット回路
- デバッグ用UART
- GPIO保護回路

#### 3. モーター制御回路
- モータードライバIC
- PWM入力
- 電流センシング（オプション）
- 逆起電力保護

#### 4. 通信回路
- UART → ステレオ4極ジャック
- ESD保護回路（TX/RX）
- プルアップ/プルダウン抵抗
- 24V電源供給ライン

#### 5. センサー入力回路
- リミットスイッチ × 2（上限/下限）
- プルアップ抵抗
- ノイズフィルタ
