## 🎯 検証目的

評価PR基板を使用して、本番PR基板設計に必要な情報を収集し、リスクを早期発見する。

---

## 📋 評価PRの仕様（推定）

### 評価PR vs 本番PR

| 項目 | 評価PR | 本番PR |
|------|--------|--------|
| **形状** | 円形板 | リング状 |
| **HR連携** | 無し | 有り（±60°回転） |
| **スリップリング** | 無し | 有り |
| **モーター** | 無し | Pitch/YAW BLDC接続 |
| **HR** | 無し | 有り |
| **真鍮線接続** | 有り（12点） | 有り（12点） |
| **マイコン配置** | 考慮なし | 最適化配置 |
| **用途** | 通信・LED・耐久性テスト | 本番展示 |

### 評価PRで検証できること
✅ 真鍮線×12の接続品質
✅ GR/CRとの通信（I2C）
✅ LED制御（NeoPixel）
✅ 電源供給
✅ ウィンチモジュールの耐久性
✅ 筒を被せたLEDの光り方

### 評価PRで検証できないこと
❌ Pitch軸回転機構
❌ スリップリング連続回転
❌ モーター制御
❌ 本番配置での干渉

## 🧪 検証項目一覧

### 1. LED光り方確認（優先度: 高）

#### 目的
- 筒を被せた状態でのLED光量・分布確認
- 前面/背面LED配置の視覚的評価
- 中心集中配置 vs 点状配置の比較（10/17会議で検討中）

#### 検証手順
1. **準備**
   - [ ] 評価PR + GR + CR組み立て
   - [ ] 筒（76mm直径）準備
   - [ ] 電源供給（5V）
   - [ ] LED制御ファームウェア書き込み

2. **前面LED確認**
   - [ ] GR前面NeoPixel全点灯（白色）
   - [ ] 筒を被せて光量確認
   - [ ] 光のムラ確認
   - [ ] 写真・動画撮影

3. **背面LED確認**
   - [ ] GR背面NeoPixel全点灯（白色）
   - [ ] 筒を被せて光量確認
   - [ ] 光のムラ確認
   - [ ] 写真・動画撮影

4. **色パターンテスト**
   - [ ] 赤/緑/青/白の単色テスト
   - [ ] グラデーション表示
   - [ ] アニメーションパターン
   - [ ] 視覚効果の記録

5. **比較検討（可能なら）**
   - [ ] 中心集中配置パターンの試作
   - [ ] 点状配置との視覚比較
   - [ ] 菅野さんへの確認

#### 成果物
- LED光り方レポート（写真・動画付き）
- 本番PR設計へのフィードバック

#### 所要時間
- 1日（11/6）

### 2. ウィンチモジュール耐久性確認（優先度: 高）

#### 目的
- ウィンチケーブル接続の耐久性確認
- スリップリング無しでの通信安定性
- 長時間動作時の発熱・劣化チェック

#### 検証手順
1. **初期状態確認**
   - [ ] ウィンチケーブル接続確認
   - [ ] 4極ステレオミニプラグ接続品質確認
   - [ ] 電源供給確認（24V → 5V）
   - [ ] 通信確認（UART）

2. **連続動作テスト**
   - [ ] 昇降動作×100回
   - [ ] 停止状態×1時間
   - [ ] 再度昇降動作×100回
   - [ ] 接続部の異常確認

3. **振動テスト**
   - [ ] 昇降中の振動測定
   - [ ] 接続部のゆるみ確認
   - [ ] ケーブル断線の兆候チェック

4. **発熱テスト**
   - [ ] 連続動作1時間
   - [ ] 接続部の温度測定
   - [ ] DCDCの温度測定
   - [ ] マイコンの温度測定

5. **劣化確認**
   - [ ] プラグ接点の状態確認
   - [ ] 配線の劣化確認
   - [ ] 基板の異常確認

#### 成果物
- 耐久性テストレポート
- 改善提案（必要時）

#### 所要時間
- 2日（11/7-11/8）

- [ ] フレームレート測定

**3-5. ウィンチ基板通信**

- 電源供給レポート

- 0.5日（11/10午前）
