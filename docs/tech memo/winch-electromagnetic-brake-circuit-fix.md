# 電磁ブレーキ回路の安全性問題と修正案

**問題報告日**: 2025-10-17
**重要度**: 🔴 Critical（安全性に関わる）
**プロジェクト**: FU@ComoNe Winch

---

## ⚠️ 問題の概要

**現在の回路の危険性**:
電源投入直後、ESP32S3がまだ起動していない間、SOLENOID端子がハイインピーダンス（Hi-Z）状態になる。この時、Q2のベースがフローティングとなり、ノイズで誤動作する可能性がある。最悪の場合、ブレーキが解除され、**ウィンチモーターが制御不能で回転する危険性**。

---

## 🔍 現在の回路の問題点

### 電源投入シーケンスの解析

```
1. 24V電源投入
    ↓
2. ESP32S3起動開始（数百ms）
    ↓
3. SOLENOID端子 = Hi-Z（GPIO未初期化）
    ↓
4. R8 (10kΩ) でQ2ベースがフローティング
    ↓
5. Q2の状態が不定
    ├─ケースA: Q2 OFF → Q1 ON → ブレーキ作動（OK）
    └─ケースB: Q2 ON → Q1 OFF → ブレーキ解除（危険！）
```

### 問題のメカニズム

**Q2ベースにプルダウン抵抗がない**:
- SOLENOID = Hi-Z の時、ベース電圧が不定
- 電源ノイズや静電気で容易に0.6V以上になる
- Q2が誤ってONになる可能性

**ブレーキ解除の危険性**:
- ウィンチモーターは常に回転方向に力がかかっている
- ブレーキ解除 = 制御不能な回転
- 負荷（筒）の落下リスク

---

## ✅ 修正案

### 修正案1: Q2ベースにプルダウン抵抗追加（推奨）

#### 回路変更

```
修正前:
SOLENOID ─── R8 (10kΩ) ─── Q2 Base
                             |
                            (フローティング)

修正後:
SOLENOID ─── R8 (10kΩ) ─── Q2 Base
                             |
                            R10 (100kΩ)
                             |
                            GND
```

**追加部品**:
- R10: 100kΩ プルダウン抵抗（Q2ベース → GND）

---

#### 動作解析

**SOLENOID = Hi-Z（電源投入直後）**:
```
R8 (10kΩ) と R10 (100kΩ) の分圧
    ↓
Q2ベース ≈ 0V（GNDにプルダウン）
    ↓
Q2 OFF
    ↓
Q1 ON（R6/R7分圧でゲート電圧あり）
    ↓
S_DRN = GND
    ↓
✅ ブレーキ作動（安全）
```

**SOLENOID = LOW（明示的なLOW）**:
```
0V ─── R8 ─── Q2 Base
                |
               R10
                |
               GND
    ↓
Q2 OFF（同上）
    ↓
✅ ブレーキ作動
```

**SOLENOID = HIGH（3.3V）**:
```
3.3V ─── R8 (10kΩ) ─── Q2 Base
                         |
                        R10 (100kΩ)
                         |
                        GND

Q2ベース電圧 = 3.3V × R10 / (R8 + R10)
             = 3.3V × 100kΩ / 110kΩ
             = 3.0V （Q2のVbe=0.6Vを超える）
    ↓
Q2 ON
    ↓
Q1 OFF
    ↓
✅ ブレーキ解除
```

**結論**: R10追加でHi-Z時にQ2が確実にOFFになり、ブレーキが作動する。

---

### 修正案2: ESP32S3のGPIO初期化を最優先（ソフトウェア対策）

#### ファームウェア修正

```cpp
void setup() {
  // ❌ 既存コード（危険）
  // Serial.begin(115200);
  // Wire.begin(8, 9);
  // ... 他の初期化 ...
  // pinMode(SOLENOID_PIN, OUTPUT);
  // digitalWrite(SOLENOID_PIN, LOW);

  // ✅ 修正後（安全）
  // 最優先: ブレーキ制御GPIO初期化
  pinMode(SOLENOID_PIN, OUTPUT);
  digitalWrite(SOLENOID_PIN, LOW);  // ブレーキ作動を明示

  // その後、他の初期化
  Serial.begin(115200);
  Wire.begin(8, 9);
  // ...
}
```

**効果**: 起動から数十ms程度でブレーキ作動を保証

**限界**:
- 完全には起動時間をゼロにできない
- ESP32S3のブートローダーが走る間（数百ms）は依然としてHi-Z
- ハードウェア対策と併用すべき

---

### 修正案3: 外部プルダウン回路（最も確実）

#### ハードウェアプルダウン追加

ESP32S3のGPIOピンに外部プルダウン抵抗を追加:

```
ESP32S3 GPIO (SOLENOID)
    |
    ├─── R11 (10kΩ) ─── GND  ← 追加
    |
    └─── R8 (10kΩ) ─── Q2 Base
                         |
                        R10 (100kΩ)
                         |
                        GND
```

**追加部品**:
- R11: 10kΩ プルダウン抵抗（ESP32S3 GPIO → GND）

**動作**:
- SOLENOID = Hi-Z の時、R11でGNDにプルダウン
- 確実にLOW状態を保証
- ESP32S3起動前から安全

## 🎯 推奨修正（修正案1 + 修正案2）

### ハードウェア修正

**変更内容**:
- Q2ベースとGND間に100kΩプルダウン抵抗（R10）を追加

**回路図**:
```
              3V3
               |
SOLENOID ─┬─ R8 (10kΩ) ─┬─ Q2 Base
          |              |
         (Hi-Z)        R10 (100kΩ)  ← 追加
                         |
                        GND
```

---

### ファームウェア修正

```cpp
// main.cpp

#define SOLENOID_PIN 10  // GPIO番号は要確定

void setup() {
  // ========================================
  // 最優先: ブレーキ制御GPIO初期化
  // ========================================
  pinMode(SOLENOID_PIN, OUTPUT);
  digitalWrite(SOLENOID_PIN, LOW);  // ブレーキ作動（安全）

  Serial.println("Brake engaged (safe)");

  // ========================================
  // その後、他の初期化
  // ========================================
  Serial.begin(115200);
  Serial.println("ESP32S3 U1 Firmware v9");

  // NeoPixel初期化
  onboardLED.begin();
  onboardLED.setPixelColor(0, 255, 0, 0);  // 赤色: 起動中
  onboardLED.show();

  // I2C初期化
  Wire.begin(8, 9);

  // UART初期化
  Serial1.begin(38400, SERIAL_8N1, 17, 18);

  // WiFi初期化
  WiFi.setSleep(false);
  connectWiFi();

  // MQTT接続
  connectMQTT();

  // 初期化完了
  Serial.println("Initialization complete");
}
```

## 🧪 修正後のテスト

### テスト1: 電源投入時の安全性確認

**手順**:
1. ウィンチモーターに負荷をかける（筒を吊るす）
2. 24V電源を投入
3. ESP32S3起動完了まで観察（数秒）

**合格基準**:
- [ ] ブレーキが作動したまま（モーターが固定）
- [ ] モーターが回転しない
- [ ] 負荷が落下しない

---

### テスト2: ブレーキ制御の動作確認

**手順**:
1. ESP32S3起動完了後、シリアルモニターで確認
2. `SOLENOID = HIGH` を送信
3. ブレーキ解除音を確認
4. `SOLENOID = LOW` を送信
5. ブレーキ作動音を確認

**合格基準**:
- [ ] HIGHでブレーキ解除
- [ ] LOWでブレーキ作動
- [ ] モーター制御が正常

---

### テスト3: 電源断時の安全性確認

**手順**:
1. モーターを回転させる（ブレーキ解除状態）
2. 24V電源を突然切断
3. モーター停止を確認

**合格基準**:
- [ ] 電源断後、即座にブレーキ作動
- [ ] モーターが固定される
- [ ] 負荷が落下しない
