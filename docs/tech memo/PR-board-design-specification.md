## 🎯 PR基板の役割

### 1. 構造的役割
- **Pitch軸回転機構**: HRの外周にリング状に取り付け、±60°傾斜可能
- **GR/CR支持**: 真鍮線を介してGridEye Ring（GR）とCompass Ring（CR）を接続
- **筒構造維持**: 筒全体の機械的強度を保つ骨格

### 2. 電気的役割
- **配線中継**: HR（FR）からGR/CRへの電源・信号中継
- **真鍮線接続点**: 12点の真鍮線接続（前面6点、背面6点）
- **Pitchモーター接続**: Pitch BLDCとの電気的接続

---

## 🏗️ 全体構造の理解

### 基板構成（修正版）

```
┌─────────────────────────────┐
│ HR (Horizontal Ring)         │ ← 水平固定、常に水平
│ = FR (Flat Ring)と同義       │
│ - ウィンチケーブル接続        │
│ - スリップリング              │
│ - ESP32-S3 #1, #2            │
│ - 24V→5V DCDC                │
│ - YAW BLDC（真下配置）        │
│ - Pitch BLDC                 │
└─────────────────────────────┘
         ↓ ±60°傾斜可能
┌─────────────────────────────┐
│ PR (Pitch Ring) ← 本設計対象  │ ← リング状、HRの外周
│ - 真鍮線接続点 12箇所         │
│ - GR/CR支持構造               │
│ - 配線中継                    │
└─────────────────────────────┘
         ↓ 真鍮線接続
┌─────────────────────────────┐
│ GR (GridEye Ring)            │ ← 評価ボード流用
│ - Grid-EYE ×2                │
│ - NeoPixel前面               │
│ - 5V→3.3V DCDC               │
└─────────────────────────────┘
         ↓ 真鍮線接続
┌─────────────────────────────┐
│ CR (Compass Ring)            │ ← 評価ボード流用
│ - AS5600（DIR）              │
│ - GY-85 IMU                  │
│ - NeoPixel背面               │
│ - 5V→3.3V DCDC               │
└─────────────────────────────┘
```

### 用語統一
- **HR (Horizontal Ring)** = **FR (Flat Ring)**: 同一基板を指す
  - 以後、HRで統一
  - 水平円形基板、常に水平、ウィンチケーブル接続点

## 🔌 真鍮線配線仕様（配線図より）

### 前面側（GR Front → PR Front → GR Back）

| 線番号 | 信号名 | 用途 | 経路 |
|--------|--------|------|------|
| W2_3 | NeoPixel Data (Front) | GRF NeoPixel制御 | GRF Ns3 → PRF Ns1 → GRB CB |
| W4_5 | NeoPixel Data (Back) | GRB NeoPixel制御 | GRF Ns4 → PRF Ns2 → GRB CB |
| SDA0 | I2C Data (Front Grid-EYE) | Grid-EYE #1 | GRF GridEye3 → PRF GR.PCB → GRB GR.PCB |
| SCL0 | I2C Clock (Front Grid-EYE) | Grid-EYE #1 | GRF GridEye3 → PRF GR.PCB → GRB GR.PCB |
| 5V | 電源 | 全基板共通 | 全基板接続 |
| GND | グランド | 全基板共通 | 全基板接続 |

### 背面側（CR Front → PR Back → CR Back）

| 線番号 | 信号名 | 用途 | 経路 |
|--------|--------|------|------|
| W6 | NeoPixel Data (Back) | CRF/CRB NeoPixel制御 | W6 → PRB → CRB |
| SDA1 | I2C Data (AS5600 + GY-85) | DIR Encoder + IMU | CRF → PRB → CRB |
| SCL1 | I2C Clock (AS5600 + GY-85) | DIR Encoder + IMU | CRF → PRB → CRB |
| W4_5 | NeoPixel Data | GR側から延長 | PRF → PRB → CRB |
| 5V | 電源 | 全基板共通 | 全基板接続 |
| GND | グランド | 全基板共通 | 全基板接続 |

### PR基板上の真鍮線接続点

**PRF (PR Front) - 6点:**
1. W2_3 入力 (GRF Ns3)
2. W4_5 入力 (GRF Ns4)
3. SDA0 (Grid-EYE #1)
4. SCL0 (Grid-EYE #1)
5. 5V
6. GND

**PRB (PR Back) - 6点:**
1. W6 入力
2. SDA1 (AS5600 + GY-85)
3. SCL1 (AS5600 + GY-85)
4. W4_5 中継
5. 5V
6. GND

**合計: 12接続点**

## ⚙️ モーター・エンコーダー配置

### Pitch BLDC + エンコーダー
- **配置**: HR上に取り付け
- **役割**: PR（リング）を±60°傾斜させる
- **エンコーダー**: AS5600（PB基板上、HRに垂直取り付け）
- **制御**: ESP32-S3 #2 Core 1

### YAW BLDC + エンコーダー
- **配置**: HRの真下
- **役割**: リアクションホイール、ケーブルねじれ補正
- **エンコーダー**: AS5600（CR基板上、DIRエンコーダーとは別）
- **制御**: ESP32-S3 #2 Core 2

### DIR（方向）エンコーダー
- **配置**: ミニプラグメス（スリップリング部）に取り付け
- **役割**: コンパス代替、筒全体の回転方向検出
- **エンコーダー**: AS5600
- **制御**: ESP32-S3 #2 Core 2

## 🔧 ESP32-S3 配置・役割（確定版）

### ESP32-S3 #1（HR基板上）
| コア | 役割 | 通信先 |
|------|------|--------|
| Core 1 | ウィンチ基板との通信<br/>ESP32-S3 #2との通信 | UART（ウィンチ）<br/>UART/SPI（S3 #2） |
| Core 2 | LED制御（NeoPixel全体）<br/>GridEye制御（Grid-EYE ×2）<br/>GY85制御（使わない可能性） | I2C（Grid-EYE via 真鍮線）<br/>I2C（GY-85 via 真鍮線） |

### ESP32-S3 #2（HR基板上）
| コア | 役割 | 制御対象 |
|------|------|----------|
| Core 1 | Pitchモーター制御<br/>Pitchエンコーダー制御 | Pitch BLDC<br/>AS5600（PB基板） |
| Core 2 | YAWモーター制御<br/>YAWエンコーダー制御<br/>DIRエンコーダー制御 | YAW BLDC<br/>AS5600（CR基板）<br/>AS5600（スリップリング部） |

## 📐 PR基板設計要件

### 1. 機械的要件

#### 形状
- **基本形状**: リング状（円環）
- **外径**: TBD mm（HRの外周に収まるサイズ）
- **内径**: TBD mm（Pitch軸機構を通すクリアランス）
- **厚さ**: 1.6mm（標準FR-4基板）

#### 取り付け
- **HR接続**: Pitch軸を中心に±60°回転可能
- **GR接続**: 真鍮線×6本（前面）
- **CR接続**: 真鍮線×6本（背面）

#### 構造強度
- 筒全体の構造を支える強度が必要
- GR（約XXg）+ CR（約XXg）の重量を支持

### 2. 電気的要件

#### 電源
- **入力**: 5V（HRから供給）
- **出力**: 5V（GR/CRへ供給）
- **電流容量**: TBD A（GR/CR消費電流 + 余裕）

#### 信号線
- **I2C×2系統**: SDA0/SCL0（Grid-EYE）、SDA1/SCL1（AS5600+GY-85）
- **NeoPixel×3系統**: W2_3、W4_5、W6
- **GND**: 共通グランド

#### ノイズ対策
- 真鍮線による信号伝送のため、ノイズ対策必須
- I2C信号のプルアップ抵抗（HR側に実装済み？確認要）
- GNDプレーン確保

### 3. 接続要件

#### HR側接続
- **コネクタ方式**: TBD（フレキシブルケーブル？ピンヘッダ？）
- **信号数**: 5V、GND、I2C×2系統、NeoPixel×3系統 = 最低9ピン

#### GR側接続（前面6点）
- 真鍮線用ランド
- 半田付けまたは圧着端子

#### CR側接続（背面6点）
- 真鍮線用ランド
- 半田付けまたは圧着端子
