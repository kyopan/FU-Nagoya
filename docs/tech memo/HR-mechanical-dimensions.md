# HR基板 機械寸法設計ワークシート

**作成日**: 2025-11-03
**担当**: kyopan
**目的**: HR（Horizontal Ring）基板の機械寸法を確定し、PR基板設計の基準を提供

---

## 📐 寸法設定の前提条件

### V1仕様（参考値）
- **筒直径**: 76mm
- **筒長さ**: 300mm

### 制約条件
1. **筒直径**: 76mm内に収める必要がある
2. **中心部**: Pitch軸機構 + YAW BLDC配置
3. **外周部**: PRリング取り付けスペース
4. **スリップリング**: 上部中心配置
5. **配線**: ウィンチケーブル、モーター配線等

---

## 🎯 HR基板の役割（再確認）

### 構造的役割
- **水平固定基板**: 常に水平、回転しない
- **ウィンチ接続**: スリップリング経由で電源・通信
- **モーター取り付け**: YAW BLDC（真下）、Pitch BLDC
- **PR支持**: PRリングをPitch軸で±60°回転可能に支持

### 電気的役割
- **電源供給**: 24V入力 → 5V変換 → 全基板へ供給
- **マイコン搭載**: ESP32-S3 #1, #2
- **モーター制御**: Pitch/YAW BLDC制御回路
- **エンコーダー接続**: Pitch/YAW/DIRエンコーダー

HR基板面積: π × (外径/2)² - π × (内径/2)²

## 📐 寸法確定の手順

### ステップ1: 中心部の決定
1. スリップリング直径確認
2. Pitch軸機構の必要径確認
3. HR内径決定

### ステップ2: 外周部の決定
1. 部品配置エリア計算
2. ESP32-S3、DCDC等のサイズ確認
3. 配置可能性確認
4. HR外径決定

### ステップ3: PRリング寸法の決定
1. HR外径確定後、PRリング内径決定
2. 真鍮線×12配置の必要幅確認
3. PRリング幅決定
4. PRリング外径決定（筒内径との整合性確認）

### ステップ4: 取り付け穴の決定
1. Pitch軸取り付け位置
2. ウィンチ懸架用取り付け穴
3. その他必要な取り付け穴
