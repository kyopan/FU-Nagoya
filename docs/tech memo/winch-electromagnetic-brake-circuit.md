# Winch電磁ブレーキ回路仕様

**プロジェクト**: FU@ComoNe (Fragmentations of Unity @ Common Nexus)
**回路種別**: 電磁励磁解除型ブレーキ制御回路
**最終更新**: 2025-10-17

---

## 📋 概要

ステッピングモーター用電磁ブレーキを制御する回路。ESP32S3からの3.3V信号で24V電磁ブレーキをON/OFF制御。

**安全設計**: 電源断時に自動的にブレーキが作動（フェイルセーフ）

## 📊 主要部品

| 部品番号 | 型番/値 | 用途 | 仕様 |
|---------|--------|------|------|
| **Q1** | 20N06 | N-ch MOSFET（メインスイッチ） | Vds=60V, Id=20A |
| **Q2** | NPN型 | 駆動トランジスタ | 汎用小信号トランジスタ |
| **D1** | SS210 | ショットキーダイオード | Vr=100V, If=2A, 高速逆回復 |
| **R5** | 1kΩ | プルアップ抵抗 | 24V電源側 |
| **R6** | 100kΩ | 分圧抵抗（上側） | Q1ゲート電圧制御 |
| **R7** | 10kΩ | 分圧抵抗（下側） | Q1ゲート電圧制御 |
| **R8** | 10kΩ | ベース抵抗 | Q2駆動電流制限 |
| **R9** | 100kΩ | プルダウン抵抗 | Q1ゲート |
| **CN3** | KF141R-2.54-2P | コネクタ | 電磁ブレーキ接続用 |

## ⚙️ 動作原理

### 信号定義

| 信号名 | 接続先 | 電圧範囲 | 説明 |
|--------|--------|---------|------|
| **SOLENOID** | ESP32S3 GPIO | 3.3V / 0V | ブレーキ制御信号 |
| **24V** | 電源 | 24V DC | メイン電源 |
| **S_DRN** | 電磁ブレーキ | 0V-24V | ブレーキコイル駆動 |
| **GND** | GND | 0V | グランド |
| **3V3** | 3.3V電源 | 3.3V | ESP32S3ロジック電源 |

---

### 動作モード

#### モード1: ブレーキ解除（モーター回転可能）

```
SOLENOID = HIGH (3.3V)
    ↓
Q2 ON → Q1 ゲートをGNDにプルダウン
    ↓
Q1 OFF
    ↓
S_DRN = 24V（R5でプルアップ）
    ↓
電磁ブレーキに24V供給
    ↓
ブレーキ解除（モーター回転可能）
```

**電流経路**:
```
24V → R5 (1kΩ) → D1 (順方向) → S_DRN → 電磁ブレーキコイル → GND
```

---

#### モード2: ブレーキ作動（モーター固定）

```
SOLENOID = LOW (0V)
    ↓
Q2 OFF
    ↓
Q1 ゲート = R6/R7分圧 (約2.2V)
    ↓
Q1 ON
    ↓
S_DRN = GND（Q1のドレイン-ソース経由）
    ↓
電磁ブレーキへの電源遮断
    ↓
ブレーキ作動（モーター固定）
```

**ゲート電圧計算**:
```
Vg = 24V × R7 / (R6 + R7)
   = 24V × 10kΩ / (100kΩ + 10kΩ)
   = 24V × 0.091
   = 2.18V
```

20N06のVth（ゲート閾値電圧）は通常1-2V程度なので、確実にON。

## ⚡ フライバック保護

### 逆起電力の発生

電磁ブレーキのコイルはインダクタンス成分を持つため、電流を遮断すると逆起電力が発生：

```
V_flyback = -L × (dI/dt)
```

**危険**: Q1のドレイン-ソース間に高電圧スパイクが発生し、MOSFETを破壊する可能性。

---

### D1（SS210）の役割

```
Q1 OFF時:
    ↓
コイルの逆起電力発生
    ↓
D1を通して24V電源に還流
    ↓
エネルギー消費（R5で放熱）
    ↓
Q1保護
```

**ショットキーダイオードを使う理由**:
- 順方向電圧降下が低い（約0.3-0.5V）
- 高速逆回復時間（通常ダイオードより10倍速い）
- スイッチングノイズ低減

## 🎯 ESP32S3制御コード

### GPIO定義

```cpp
#define SOLENOID_PIN 10  // 仮のGPIO番号（要確定）

void setup() {
  pinMode(SOLENOID_PIN, OUTPUT);
  digitalWrite(SOLENOID_PIN, LOW);  // 初期状態: ブレーキ作動
}
```

---

### ブレーキ制御関数

```cpp
// ブレーキ解除（モーター回転許可）
void releaseBrake() {
  digitalWrite(SOLENOID_PIN, HIGH);
  delay(50);  // ブレーキ解除待ち（機械的遅延）
}

// ブレーキ作動（モーター固定）
void applyBrake() {
  digitalWrite(SOLENOID_PIN, LOW);
  delay(10);  // ブレーキ作動待ち
}
```

---

### モーター制御シーケンス

```cpp
void moveMotor(int steps) {
  // 1. ブレーキ解除
  releaseBrake();
  Serial.println("Brake released");

  // 2. モーター駆動
  for (int i = 0; i < steps; i++) {
    stepMotor();  // ステッピングモーター駆動関数
  }

  // 3. 惰性回転待ち
  delay(100);  // モーター停止待ち

  // 4. ブレーキ作動
  applyBrake();
  Serial.println("Brake applied");
}
```

---

### 緊急停止

```cpp
void emergencyStop() {
  // モーター駆動即座停止
  stopMotor();

  // ブレーキ即座作動
  digitalWrite(SOLENOID_PIN, LOW);

  Serial.println("EMERGENCY STOP - Brake applied");
}
```

## 🔧 設計上の考慮事項

### 1. 発熱対策

**ブレーキコイル**:
- 連続通電時、コイルが発熱
- 推奨: 長時間停止時はブレーキ解除を避ける

**Q1 (20N06)**:
- ON時のRds(on) ≈ 0.05Ω
- 発熱: P = I² × Rds(on) = 1A² × 0.05Ω = 0.05W（問題なし）

**R5 (1kΩ)**:
- フライバック時の電流: I = 24V / 1kΩ = 24mA
- 発熱: P = I² × R = (24mA)² × 1kΩ ≈ 0.58W
- 推奨: 1/2W以上の抵抗を使用

---

### 2. ノイズ対策

**電源ノイズ**:
- スイッチング時に24V電源にノイズ発生
- 対策: 24V電源ラインに100μF電解コンデンサ + 0.1μFセラミックコンデンサ

**制御ノイズ**:
- SOLENOID信号にノイズが乗るとブレーキが誤動作
- 対策: ESP32S3近くに0.1μFバイパスコンデンサ

---

### 3. フェイルセーフ

**電源断時**:
- Q2がOFF → Q1がON → ブレーキ作動
- モーターが自動的に固定される（安全）

**ESP32S3リセット時**:
- GPIOが初期状態（通常LOW）→ ブレーキ作動
- モーターが固定される（安全）

### 1. 静的テスト

```cpp
void testBrakeCircuit() {
  Serial.println("=== Brake Circuit Test ===");

  // 初期状態確認（ブレーキ作動）
  digitalWrite(SOLENOID_PIN, LOW);
  delay(100);
  // 目視: S_DRNが約0Vであることを確認

  // 目視: S_DRNが約24Vであることを確認

}
```
